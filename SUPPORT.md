# Support

Start with the [quick start](README.md#quick-start),
[operations guide](docs/operations.md), and [validation record](docs/validation.md).
The latter distinguishes tested behavior from environment-specific limits.

For a reproducible failure, open a bug report with the commit, tool versions,
steps, expected behavior, and relevant redacted diagnostics. Use a feature request
for a proposed capability or documentation improvement. Small documentation fixes
can go directly through a pull request.

This is a development platform maintained as an open-source project. Support is
best effort; there is no response-time or production support commitment.
Security reports belong in the [private reporting channel](https://github.com/VillaforTech/kubernetes-mlops-platform/security/advisories/new),
not in public issues.
