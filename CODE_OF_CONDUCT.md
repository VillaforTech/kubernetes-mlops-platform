# Code of conduct

Keep issues, reviews, and discussions respectful and focused on the work.
Welcome questions, explain technical disagreements, and give specific,
constructive feedback. Respect people's privacy and the limits of a volunteer
maintained project.

Harassment, discriminatory language, threats, personal attacks, and publishing
someone else's private information are not acceptable. Maintainers may edit or
remove inappropriate contributions, close disruptive conversations, or restrict
participation when needed.

Use GitHub's **Report content** option for abusive content. Report technical
vulnerabilities through the private channel described in [SECURITY.md](SECURITY.md).
Do not put personal or sensitive information in a public issue.

These expectations apply to this repository's issues, pull requests, reviews,
and other project spaces on GitHub.
